Auto Translate Privacy Policy

Auto Translate sends the text it translates to Google Translate, and nothing else to anyone. I don't run any servers and I don't collect anything about you.

Applies to the Auto Translate extension for Chrome · Last updated: November 14, 2026

Data I collect

None. Auto Translate has no accounts, no analytics, no advertising and no tracking code. It never sends anything to me.

What is sent to Google for translation

To translate, the extension sends text to Google Translate and puts the result back on the page:

  • Web page text. When a page is in a language you don't read, the visible text of that page (and labels such as placeholders, tooltips and image descriptions) is sent to Google Translate. Pages in your own languages, sites you've marked “Never translate”, and all pages while automatic translation is off are not sent.
  • Text you type, only when you ask. Text in a text box is sent only when you press the convert button or its keyboard shortcut. Text you type is never sent otherwise, and password fields are ignored.

By default the text goes to Google Translate's web service (translate.googleapis.com). If you add your own Google Cloud API key in Settings, it goes to the Google Cloud Translation API (translation.googleapis.com) under your Google Cloud account instead. Either way Google handles it under the Google Privacy Policy.

The extension sends only the text to be translated and the languages involved. It does not send your browsing history, the addresses of the pages you visit, or any information about you.

Stored in your browser

  • Your settings: your languages, whether the text-box button is on, and the list of sites you chose never to translate. These are kept in Chrome's storage and, if you use Chrome sync, follow your Google account to your other computers.
  • Your Google Cloud API key, if you add one. It is kept only on this computer and only sent to Google with translation requests.
  • Recent translations are kept in memory so the same text isn't translated twice. They are discarded when Chrome closes the extension's background process.

Remove the extension to delete everything it stored.

Permissions

Read and change data on websites is needed to find a page's text, replace it with the translation, and show the convert button inside text boxes. Storage keeps your settings. Access to translate.googleapis.com and translation.googleapis.com is used only to request translations.

How data is used

Text is used only to translate it for you. It is not sold, not used for advertising or credit decisions, and not shared with anyone other than Google for the translation itself. The use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Children

Auto Translate doesn't collect personal information from anyone, including children.
